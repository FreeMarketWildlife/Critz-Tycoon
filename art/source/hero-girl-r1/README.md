# M1.GH1 editable front-only source

One static Girl Hero front idle and a matching color-coded construction map, UNAPPROVED. [Review and exact scope](../../../docs/reviews/M1-GH1/README.md).

`build.py` derives the original native head from the selected C6 project and a declared shared body from HR14's checked original body layer. It never uses the generated concept raster or reference-game pixels. `construction.json` preserves source hashes, visible feature masks, bounded ear override, material sites, edge anchor and unresolved anatomy. `present.py` builds native/nearest review plates; `verify.py` checks actual saved pixels.

Both `.sprite.json` files open with the existing Sprite Editor. No other directions, walks, runtime replacement, Library writes or website deployment are included.
