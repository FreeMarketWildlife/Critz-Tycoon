# M1.OGH3 editable walking study

Four directions, native32×64, three unique poses each (exact OGH2 idle and two original strides), four playback slots A/idle/B/idle. Ordinary source8-update holds, fixed frame-edge anchor(16,64), rigid+2Y head/torso stride bob, full shoe volume and coordinated arm phase. Candidate appearance/motion awaits parent/user judgment; no runtime adoption.

Actual semantic PNGs and ordered indexed pixel layers exactly recompose each saved composite. Four `*.walk.sprite.json` files reopen in the existing Sprite Editor. `construction.json` records pinned source-frame order/contact/timing and original occlusion proposals. `build.py` writes only this folder and `docs/reviews/M1-OGH3/`; `verify.py` checks saved outputs and unchanged OGH2 files. Use bundled Python/Pillow. Do not execute archived historical builders.

See `docs/reviews/M1-OGH3/README.md` for the one bounded far-shoe material correction, normal/slow native/integer GIFs, exact-clock local viewer, actual sampled/paused viewing, checks and limitations.
