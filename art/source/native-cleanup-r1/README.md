# NCR1 editable source

Run bundled Pillow Python on `author.py`, then `build.py`. The first writes deliberate native cell maps and edit reasons from the rejected H4R1 correspondence trace. The second applies documented original NWE master material/optional rear-hair changes and reads those native maps without image reduction, interpolation or palette voting. It checks saved outputs, actual layer recomposition, contacts/features/observed-pack consistency and exact GIF frames. All historical files are read-only inputs.

Repeatable review order: inspect pinned source + actual current artifact; diagnose whole contour/material issues before editing; establish shared body/feature/ground contracts; author complete native clusters across every existing pose; keep hair/shadow/occlusion separate; compare actual before bald as well as Hero at equal apparent/native size; inspect every unique pose and normal-speed loop; measure invariants and declared coarse losses; independent/private visual judgment. Counts and preserved footprints are guardrails, never appearance approval.

Only NCR1-owned output paths may be regenerated. Root owns independent/private review subdirectories and uploads. Creator, gameplay, saves and deployment are out of scope.
