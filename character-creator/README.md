# Hero Workshop — isolated character creator review

Open `/character-creator/` on a local server rooted at this repository. This is the bounded BS2-backed review prototype; it has no game-state imports, browser storage or save integration. It is deliberately excluded from `scripts/build.mjs` and has not been deployed or adopted into gameplay.

Three hairstyles (original twists, original close crop, bald), three hair colors/skin tones, classic/short/amber eyes, folded/soft ear shading, three same-footprint shoe materials, optional nose, and none/line/smile mouth. Default nose and mouth are none. Same starter clothes, full shoes, frame/anchors and existing gait. Original defaults are exact FM2; bald defaults are exact accepted BS2. PM1 is excluded. Ear and shoe options are material/feature variants inside fixed silhouettes, not body-type expansion. Original twists retain their recorded occlusion of some ear-edge sites; crop and bald expose the existing template's ears.

Play/pause freezes the actual frame; rotate preserves slot/progress, Next frame advances existing slots, Idle and Reset restore their stated states. Main preview uses4× desktop/3× phone, native preview1×, four-view matching-pose lineup2×. Slow changes elapsed playback speed only. Controls use native keyboard-accessible elements and44px minimum targets.

PNG export captures the selected current/pause pose. The editable JSON is explicitly a16-unique-static-pose collection, with separate original walk-order/duration metadata. GIF export uses the current direction's existing8-slot walk. The creator-local adapter preserves the recorded centisecond holds rather than allowing tick rounding to shift the short hold to another frame. No editor or gameplay code was changed.

Data is regenerated by `art/source/creator-r2/build.py` from actual BS2 clean bases, original hair, sparse hair-dependent skin shading and registered source features. The obsolete NB3 draft generator is historical and no longer supplies this tool. No naked anatomical mannequin is used under the source outfit.
