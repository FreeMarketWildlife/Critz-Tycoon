# M1.DUI2 — canvas-first phone/tablet editor

Phil requested a less busy mobile editor, tabs, and full screen adaptation to phones and tablets. Dummy Creator now opens on Canvas with panels hidden. Draw, Frames, View and File reveal one set of controls at a time. Undo/Redo/Copy and zoom remain visible. Selecting a direction or part button returns to Canvas; Done, Canvas and Escape also dismiss panels. Arrow/Home/End keys navigate the tablist with selected states and roving focus.

Phones use a scrollable lower sheet. Tablets use a side panel with canvas refitting; short landscape uses a side overlay. The app uses the dynamic viewport and safe-area insets. Compact mode covers widths through1100px, or coarse-pointer tablets through1400px. Returning to desktop restores the exact existing control nodes and their prior positions. No duplicate controls, model migrations, storage keys, artwork or timing changes are introduced. Compact entry always starts with panels closed, independently of saved desktop dock preferences.
