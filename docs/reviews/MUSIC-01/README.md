# MUSIC.01 — A Tiny World

**Composition/export complete; awaiting the user’s listening review.** Thirty original Critz: Tycoon MIDI compositions and matching custom-synth MP3 performances, 47 minutes 56 seconds total. The latest user request authorizes this separate collection; no soundtrack is silently integrated into gameplay and no art/movement gate is self-approved.

[Listening room](https://critz-tycoon.freemarketwildlife.chatgpt.site/music/) · [All 30 MIDI files](../../../music/critz-tycoon-30-midi.zip) · [Research](RESEARCH.md) · [Editable sources](../../../music/source/README.md).

Every track includes an individual story, two melodic ideas, authored answering phrases, a developing arrangement and an ending. The title motif returns in the finale. The collection spans home, cute, friendship, curiosity, adventure, melancholy, relief, scary, danger, battle, resolve, joy, forgiveness, recovery, wonder, chill, nostalgia and peace. Future locations/battles remain musical proposals, not implemented canon.

## Actual checks

- All 30 exported MIDI files independently parsed: Type 1, 480 PPQ, eight named tracks including conductor, balanced note on/off events, no duplicate active same-pitch notes, monophonic bend channels, velocity variation, six program changes, real nonzero pitch-wheel events, consistent duration, and two loop markers. All 30 lead fingerprints differ. This is not a statistical proof of originality against every existing song.
- All 30 MP3s independently decoded; no nonfinite samples, clipping, unexpected interior silence or duration mismatch. Measured integrated loudness −16.8 to −15.9 LUFS; true peaks −3.8 to −1.9 dBFS. Stereo correlation 0.952–0.989 preserves strong mono compatibility. [Full audio/MIDI report](validation.json).
- Nine isolated Chromium browser scenarios pass, including **actual playback and B-section seeking for every track**, real end-of-file next-track/final-stop behavior, repeat setting, all mood/search states, MIDI downloads, recoverable audio failure, one-player exclusivity, untouched synthetic v1 save, and no runtime errors. No overflow at 1366, 390, 320 and 844 px. [Report](browser-report.json).
- Initial local seeking failed because the preview server omitted media ranges. Added MP3 byte-range support; actual closed, open-ended and suffix HTTP ranges returned exact expected bytes. Repeated browser checks pass after the fix.
- [Desktop](listening-room-1366.png) and [phone](listening-room-390.png) screenshots visually inspected. Physical iPhone/Safari and a human listening review were not available. Technical validation does not establish artistic acceptance.
