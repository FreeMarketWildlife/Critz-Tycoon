# M1.NB3 — Existing bald-base pose candidate for PS1

**Four directions, existing idle/A/P/C only; full foundation awaiting independent review.** Extends the prior supported separate body/skin/costume architecture to the existing poses, paired with PS1's native-grid side/back candidate. This is the requested bald-base completion candidate, not a creator or body-type/anatomy expansion.

Actual head, torso, pelvis, two arm/hand, two leg/foot RGBA files and cell masks are stored for every pose. The head is bald; hair/collar/pack remain outside the base. Visible face/eye/ear/hand pixels belong to the body renderer, never a full opaque Hero image called clothing. Each pose has actual skin/body contribution, removable individual costume overlays, body-only/single-garment views, explicit z-order, visible-body part masks, coverage cells and exact corrected-Hero recomposition.

South idle's32 prior PNGs remain exact to NB1. Profile neutral support extends only at eight actual brown face/nape cells per pose, not dark collar pixels. Per-view eye masks and collar ownership use actual view data. No long standalone neck part is introduced. Profile far arm/leg layers sit behind the core, near arm/leg in front; frontal opposing strides choose foreground leg from their declared near contact. These hidden shapes/connections are authored reconstruction, not source-measured bones.

Bare feet are compact rounded8-cell surfaces, separately stored from shoes and with at least2-cell own-leg overlap. Existing contact rows/frame/anchor are retained. Some reconstructed stride surface lies outside the selected clothed silhouette; the explicit dressing stencil conceals3–11 cells in affected strides (none in any idle/P), rather than silently altering the unclothed mannequin. Exact lists and per-part z/visibility masks are in `art/source/hero-neutral-r3/construction.json`; this is current-outfit compatibility evidence, not proof of arbitrary swaps. Independent judgment must assess those occlusions and gait attachments.

Saved-layer/connection/ownership and native GIF checks are in [PS1 checks](../M1-PS1/checks.json).
