## Bounded choices and behavior

Original twists, close crop and bald; original/black/warm hair colors; three skin ramps; classic/short/amber eyes; folded/soft ear shading; trail/forest/midnight shoes with identical footprints; optional small nose; no mouth by default, small line or smile. Default nose is also none. Same starter shirt/shorts/backpack, full body/shoes,32×64 frame and anchor16,64 throughout. PM1 is NOT included. These new appearance choices are original Critz review proposals, not new reference facts or accepted roster art.

Defaults reproduce all16 selected FM2 dressed images exactly; bald reproduces all16 BS2 bases exactly. Original hair, sparse skin/nape shadows and new close-crop art are separate. Alternate skin ramps recolor exposed hair-dependent shadows too, avoiding an original-color fringe. The crop respects actual eye/ear registration. Original twists retain existing ear-edge occlusion; ear/shoe variants are fixed-silhouette feature/material choices, not a new anatomical body.

Pause freezes the current walk frame and resumes it; rotate preserves slot/fraction, Next frame steps the existing sequence, Slow runs at quarter speed, and Reset restores original look/no nose/no mouth/front idle. Four-view lineup compares the same current pose, derived before cache evaluation. Native preview1×, main4× desktop/3× phone and lineup2× all use integer nearest pixels.

PNG export is the exact current selected/pause pose. Editable JSON is honestly labeled a collection of16 unique static poses, with separate `A,A,P,P,C,C,P,P` order, holds and source tick metadata. Current-direction GIF export preserves all8 slots, exact recorded South `[100×8]` or NWE `[70,60,70,70,70,60,70,70]` millisecond holds and infinite loop. A real export-proof failure caught the editor's generic tick-rounding distribution; a creator-only structural GIF control-block adapter fixes it without modifying the editor or pixels.
