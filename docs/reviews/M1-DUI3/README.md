# M1.DUI3 — vertical mobile canvas hotbar

The requested right-side stack is Move, Pencil, Eyedropper, Forward one frame, Backward one frame, Reference visibility and Dummy visibility. The rail reserves56px beside the canvas and uses48px-high targets. It remains vertical on phones/tablets and scrolls in short landscape layouts. Existing tabs remain; phone sheets leave the rail reachable. Desktop docks remain present and the mobile rail hides above compact breakpoints.

Selecting the drawing slot activates its current tool; tapping the selected slot again opens a Pencil/Fill/Line/Erase flyout. Menu focus, Escape, outside taps, checked/pressed/expanded states and accessible action names are provided. Move pans the viewport. Reference/Dummy visibility buttons call the existing checkboxes and stay synchronized with View-tab changes. Frame buttons use existing previous/next actions, including wraparound and current-direction behavior.

This is an anatomical-label editor. Eyedropper reads the exact dummy label ID, chooses its category and anatomical side, and returns to Pencil without editing data. A hidden dummy must be shown first; reference RGB is not converted into arbitrary part labels. Fill finds the four-connected region of the same exact ID from a frozen label snapshot, then uses existing side/mirror painting. Line previews as an overlay until release and commits one native line. Preview cancellation edits nothing; cancelled paint/fill restores its tentative stroke. Native right-click erase, shared poses, single-stroke Undo/Redo and established storage/schema/part IDs remain intact.
