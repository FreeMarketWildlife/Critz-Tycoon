# Reusable art-task prompt

Copy the following into a task and add the specific asset(s) and requested pose/animation scope.

---

Read `AGENTS.md` for project workflow and `docs/ART_BIBLE.md` for the current art direction before creating or editing an asset. ART_BIBLE is the single art specification; follow its current correction and the user's latest instructions over historical examples. Do not infer required anatomy or painted height from canvas capacity or a reference hat's highest pixel.

Read current status/plan and relevant reference measurements. Identify the active deliverable, distinguish measured source features from proposed original construction, and show applicable reference landmarks/targets before drawing. Preserve character identity and the requested review scope. Deliver the requested visual with the Art Bible's current grid/coordinate convention, editable native sources, relevant checks and honest limitations. Record new lessons in ART_BIBLE rather than duplicating direction in AGENTS or this prompt. Final artwork acceptance belongs to the user.
