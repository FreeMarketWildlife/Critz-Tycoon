Choose terrain or a whole prop in Build. Search finds both.

3. Take a walk

Keyboard & navigation

B Brush · R Rectangle · F Fill · E Erase · S Select · H Pan · I Pick
Space + drag: pan · Ctrl/⌘ + scroll: zoom
Ctrl/⌘ Z: undo · Ctrl/⌘ Shift Z: redo
Focus canvas: arrows move cursor, Enter places; Shift + arrows selects.
Ctrl/⌘ C / V: copy / paste selection · Escape cancels.

Layers, collision & rooms

View shows the grid, blocked cells and a layer filter. Auto follows your chosen tool. Shallow water is walkable; deep water and banks block walking. Use More tools → Add passage on a building to connect a room and return exit.

Your draft saves on this device. Project → Save project downloads a backup. Copy for chat shares the complete editable map.

Map settings

Shrinking crops content and removes cropped passages and paired return links. Editable rooms remain. Undo restores it. Maximum 128 × 128; 16 maps per project.
